# Required IIS installers

Before running `setup-host-pc.cmd`, download company-approved copies of these MSI installers and place them in this folder:

- `url-rewrite.msi` — IIS URL Rewrite Module
- `arr-setup-x64.exe` — IIS Application Request Routing (ARR) x64 setup bundle

They are intentionally not bundled here. Verify their source and signature according to company policy before use.

Download URL Rewrite 2.1 x64 from the [official IIS URL Rewrite page](https://www.iis.net/downloads/microsoft/url-rewrite), rename it to `url-rewrite.msi`, and save it here.

Download ARR 2.0 x64 from the [official Microsoft download](https://download.microsoft.com/download/3/4/1/3415F3F9-5698-44FE-A072-D4AF09728390/ARRv2_setup_x64.EXE), rename it to `arr-setup-x64.exe`, and save it here.
